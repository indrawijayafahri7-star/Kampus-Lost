# Kampus Lost

Kampus Lost adalah prototipe sistem informasi barang hilang dan ditemukan yang dirancang untuk membantu mahasiswa mencari serta melaporkan barang di lingkungan kampus.

## Fitur Utama

- Beranda sebagai halaman utama.
- Cari barang menggunakan filter status, kategori, lokasi, dan waktu.
- Detail informasi barang.
- Formulir pengajuan klaim barang.
- Formulir laporan barang hilang dan ditemukan.
- Halaman konfirmasi laporan.
- Profil dan riwayat laporan.

## Teknologi

- HTML5
- CSS3
- JavaScript
- Local Storage

Kampus-Lost/
├── index.html
├── style.css
├── script.js
└── README.md

## Cara Menjalankan

1. Clone atau download repository Kampus Lost.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Pastikan file `index.html`, `style.css`, dan `script.js` berada dalam satu folder.
4. Jalankan `index.html` menggunakan ekstensi Live Server.
5. Website akan terbuka melalui browser.

Proyek ini merupakan prototipe untuk tugas Frontend Lab. Pengembangan difokuskan pada implementasi struktur HTML, styling CSS, interaksi JavaScript, dan navigasi ant halaman.
